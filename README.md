# Diapasón

Afinador y metrónomo para el teléfono, hecho como aplicación web instalable (PWA).

- Afinador para instrumentos de cuerda (guitarra, bajo, ukelele, violín) y de viento (quena en Sol mayor, flautas, oboe, clarinete, trompeta, saxos, corno y trombón).
- Notación latina (Do Re Mi) o anglosajona (C D E).
- Metrónomo mecánico con tap tempo.
- Funciona sin conexión una vez instalada.

Sitio: https://thunder1965.github.io/guitartune/
